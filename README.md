# mcp_practice

Welcome! This repository is a practice space for learning the **Model Context Protocol (MCP)**.

MCP is an open standard that lets AI assistants connect to external tools and data sources, such as GitHub, Gmail, Google Drive, and databases, through a common interface.

## What this repo is for

- Experimenting with MCP servers and clients
- Trying out tool calls from Claude Code
- Keeping notes and small examples while learning

## Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/ciahjh/mcp_practice
   cd mcp_practice
   ```
2. Open it in your editor or Codespace.
3. Start experimenting with MCP!
